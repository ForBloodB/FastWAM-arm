# EVOArm — 面向未知环境的自进化智能机械臂

本仓库交付 **仿真验证与历史 FPGA 分项联调**。真实纸盒抓放、连续 SAC 残差控制、在线学习增益及整机端到端加速尚未完成验收。登记作品名称中的“自进化”是研发目标，不代表这些指标已经实现。

## 2026-11-02 独立复验

| 实验 | 对照 | 结果与边界 |
|---|---|---|
| 60 个新场景，含 48 个低摩擦金属代理场景 | 零残差 / 固定规则 / 冻结 / 在线 | 24/60 → 30/60；后三者相同，三个训练种子一致 |
| 同场景风险审计 | 相同原有夹持力上限 | 无过夹、无超力；本批逐场景峰值均未增加；历史另一批曾有峰值增加，不能宣称全域安全 |
| 在线更新 | 24 个适应场景 × 3 个种子 | 每种子 192 次梯度更新；每种子 6 个候选块均因效用增益不足被拒绝；没有在线净收益 |
| 41×31×37 mm 空纸盒 | 2.5 N / 1.5 N 初始驱动力目标 / 仅换颜色 | 各 40/40 成功；最大指端力 1.560 → 0.961 N（−38.4%），共同 3 N 上限 |
| 纸盒数值复验 | 62.5 / 31.25 / 15.625 μs | 8 场景，24 试次，最大相邻步长力峰差 0.001465 N，标签一致 |

**算法身份：** 当前可复现学习器是一次任务一个动作选择的 15 维神经上下文老虎机（contextual bandit），64×64 MLP、Huber 回归、Adam；不是 SAC，也不是连续时序 TD 控制。三个种子使用相同测试场景，不能把 60 场景写成 180 个独立样本。相同选择共享确定性物理轨迹：60 场景实际积分 68 个唯一测试轨迹，产生 480 条策略关联记录。

**模型边界：** 官方 Seeed B601-RS 模型的 URDF、网格与派生转换审计均保留。空纸盒使用薄壁质量/惯量与刚性外碰撞包络；尺寸来自测量，厚度、密度和摩擦仍是假设，不能证明真实纸盒不被压坏。深度几何定位假设已知单目标和工作区域，未完成未知材质识别。

## 复现

Linux x86-64、Python 3.12、gcc、可用的 EGL/OpenGL（原实验使用 MuJoCo 3.3.7 和 Torch 2.8.0 CPU）。

```bash
cd simulation
python3.12 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python reproduce.py build
python reproduce.py smoke
python reproduce.py train
python reproduce.py adapt --workers 3
python reproduce.py test --workers 8
```

`build` 从随附 C 源码及官方网格生成本地动态库与模型缓存。`smoke` 在新目录复算首个已声明纸盒场景；`train` 要求三个模型权重摘要与已发布结果完全一致；`adapt/test` 重放原先声明的场景，不是又一个独立测试集。新结果写在 `runs/reproduced_*`，不会覆盖原始证据。

完整纸盒三档步长和 40 场景三模式复算可在另一份干净副本中运行 `scripts.run_submission_paper prepare/numerics/test`；先将模块的 ROOT 指向不存在的新目录。公开包修复了汇总中 numpy.bool_ 的 JSON 编码问题，没有修改接触、力限、动作或结果判定。

## 文件

- `simulation/reflex/`：物理模型、反馈、控制、动作屏蔽与学习模块。
- `simulation/scripts/`：本次实验所需源码及构建依赖。
- `simulation/runs/submission_*`：声明、训练回放、模型、逐场景结果及更新接受/拒绝记录。
- `analysis/`：逐场景 CSV、汇总指标、数据审计。
- `fpga_reference/`：历史 DMA/AXI-Stream RTL、驱动及构建源代码；当前仿真入口不访问开发板。
- `evidence/fpga/`：匿名化时序与资源报告，原始指标未改。

完整原生步长轨迹保留在实验归档中，未装入受 200 MB 限制的代码包。每份结果包含对应轨迹 SHA-256；公开包保留所有本批场景汇总、模型和复现代码，不删除失败样本。

## FPGA 证据边界

历史 8 场景硬件在环中本地、板端 CPU、MMIO、DMA 均 7/8 成功，标签一致。128 帧图像处理端到端 P50：本地 CPU 1.435 ms、远端 CPU 36.862 ms、MMIO 79.560 ms、DMA 36.285 ms。DMA 优于远端 MMIO，但没有快于本地 CPU；任务整段 local/DMA 时间比中位数 0.901，不能宣称整机加速。当前纸盒策略没有运行在 FPGA 上。
